## Core Stack (most common)

1. **Relapse-Exploit** — Kernel jailbreak (FW 7.00–13.60)
2. **ps5-webkit-autoloader** — Entry / autoloader
3. **kstuff-lite** — Kernel patches
4. **ShadowMountPlus** or **etaHEN** — Game mounting + homebrew

## Game Compression Tools

- [ps5-dump-forge](https://github.com/quer3q/ps5-dump-forge) — Pack games into zstd or LZ4
- [ampr-emu-ng](https://github.com/quer3q/ampr-emu-ng) — Runtime that reads the packs on the PS5
